# 🔄 Universal File Converter

A simple Streamlit app to convert files between common formats — text, spreadsheets, documents, and images — right from your browser.

## Features

- **Text**: `.txt` → PDF, HTML, JSON
- **Spreadsheets**: `.csv`, `.xlsx`, `.xls`, `.json` → converted between each other and `.txt`
- **Documents**: `.docx` → TXT, PDF | `.pdf` → TXT | `.html` → TXT, HTML
- **Images**: `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff` → converted between each other

## Installation

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
pip install -r requirements.txt
```

## Usage

```bash
streamlit run formate_to_formate.py
```

Then open the local URL shown in your terminal, upload a file, choose the output format, and click **Convert**.

## Requirements

- Python 3.8+
- See `requirements.txt` for all packages
